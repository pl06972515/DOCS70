>
>  <span style='color:Blue'>[`C`] 细化领域：梳理领域概念、梳理业务规则、梳理业务场景、梳理业务流程</span>
>
>---
>
><span style='color:Blue'>【概念：领域子域】</span>
>
>- 领域 ( 业务问题域 ) 具体指一种特定的范围或区域 <span style='color:RED'>[ 就是用来确定范围的，范围就是边界 ]</span> <span style='color:Blue'>( 细分 - 限定 - 领域模型 - 代码实现 )</span>
>
>  领域越大 [ 业务范围就越大 ]
>
>  领域可以进一步划分为 [ 子领域 - 子域 - 更小的单元 ]
>
>  <span style='color:red'>[ 领域建模的过程和方法其核心思想：就是将问题域逐步分解 - 降低业务理解 + 系统实现的复杂度 ]</span>
>
>![Q1](wwwroot\DocImages\c2.0.1.png ':size=500')
>
>- <span style='color:Blue'>子域的三种类型：</span>
>
>  [`A`] <span style='color:red'>核心域：</span>产品核心的业务功能 ( 关注点不一样：公园里面的桃树关注花，田地里面的桃树关注果实 ... )
>
>  [`B`] 通用域：被多个子域使用的 [ 通用功能 ]
>
>  [`C`] 支撑域：既不包含业务核心功能，也不包含通用功能
>
>---
>
><span style='color:Blue'>【概念：通用语言】</span>
>
>- <span style='color:red'>通过团队交流达成共识的，能够简单、清晰 [ 准确描述业务涵义和规则的语言 - 通用语言 ]</span>
>
>- 通用语言中：[ 名词表示领域对象 ] [ 动词表示动作或事件 ]
>
>  术语、用例场景
>
>  名词 → 领域对象命名 ( 商品、订单 )
>
>  动词 → 动作、事件 ( 商品已下单、订单已付款 ) → 领域事件、命令
>
>---
>
><span style='color:Blue'>【概念：实体和值对象 - 代码战术设计】</span>
>
>- 实体和值对象都是领域模型中的 <span style='color:Blue'>[ 领域对象 ]</span>
>
>  <span style='color:red'>领域驱动设计中要求实体是 [ 唯一的且可持续变化的  ] ( 实体：并不完全等同于实体类 )</span>
>
>  <span style='color:red'>[ 唯一性：由唯一的身份标识来决定的 ] [ 可持续变化：反映了实体本身的状态和行为 ]</span>
>
>  [`A`] 业务形态：战略设计 [ 领域模型基础单元、操作、行为 ]
>
>  <br/>
>
>  [`B`] 代码形态：实体类、属性、方法<span style='color:Blue'> ( 实现业务逻辑 - 充血模型 )</span>
>
>  [ 只把和实体自身状态 - 密切相关的业务逻辑 ] 放在实体内部 [ 比如状态变更、合法性校验等 ]
>
>  <span style='color:red'>[ 跨实体、跨聚合的业务逻辑 ]</span> 指的是涉及多个实体或多个聚合根之间协作、交互的业务规则或操作 ( 应放在领域服务`DomainService`中 ）
>
>  <br/>
>
>  [`C`] 运行形态：实体对象，唯一ID
>
>  [`D`] 数据形态：领域模型 ( 实体对象、行为 - 数据模型 )
>
>  <br/>
>
>- 值对象：属性集合 ( 拥有若干个用于描述目的、具有整体概念和不可修改的属性 )
>
>  <span style='color:red'>[ 值对象就是将一个值 → 用对象的方式进行表述，来表达一个具体的固定不变的概念 ]</span>
>
>---
>
><span style='color:Blue'>【概念：聚合】</span>
>
>- <span style='color:red'>聚合：将相关的领域对象进行显示分组 [ 来表达整体的概念 ]</span>
>
>  聚合由 [ 业务 ] 和 [ 逻辑 ] 紧密关联的实体和值对象组合而成的 ( 是数据修改和持久化基本单元 )
>
>  <span style='color:red'>[ 聚合有一个聚合根和上下文边界 - 聚合之间的边界是松耦合的 ]</span>
>
>  个体 ( 实体、值对象 ) ：社团、机构、公司，组织里的一员
>
>  聚合 ( 组织 ) ：实体 + 值对象，聚合根 ( 负责人、实体ID、聚合的管理者、负责内部协调 )
>
